Learning / Architecture

This dashboard is intentionally thin: the browser calls the FastAPI backend, the backend uses PostgreSQL for the review ledger, the knowledge service for verified context, and a local model provider for drafts. Publishing is a separate controlled operation.

Google → ingestion → PostgreSQL → policy → knowledge → local AI → safety gate → approval → Google
